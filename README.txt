# Operation Baby Reveal

## Change the answer
Open `index.html` and find:

const SECRET = "boy";

Change it to:

const SECRET = "girl";

## Publish it
The easiest option is GitHub Pages:
1. Create a new GitHub repository.
2. Upload `index.html`.
3. Go to Settings -> Pages.
4. Choose "Deploy from a branch", select `main` and `/root`.
5. GitHub will give you a shareable URL.

The page is completely self-contained. No external libraries or images are required.
